# 思维导图侧栏

把当前笔记整篇画成思维导图，直接在新标签页里看整张图，不用在笔记里写代码块。

- 点命令面板、编辑区右键菜单里的「打开思维导图」，整张图就在一个新标签页里展开；左侧栏大纲标签旁的思维导图图标也还能用，只是画在侧栏里。笔记一改，图跟着重画。
- 全文只有一个一级标题时，这个标题就是根节点；否则根节点是这篇笔记的文件名（不带路径）。正文里的标题和列表都是它的分支。
- 节点的框按画出来的文字宽度算，长标题、中文、emoji 都装得下，不会冒出框外。一行超过各自角色的换行预算就拆成几行，画进一个高一点的方框里，一条很长的节点不会把整张图拉得老宽：根基本保持单行，分支标签早一点换行让骨架更窄，列表叶子项短的时候保持单行、长到一定程度才换行。
- 缩放旁的「展示层级」决定画到第几层：默认 4 层，最多 10 层。被层级挡住孩子的节点，右端的小圆圈画成加号，点它把层级放开一层。
- 有子节点的节点，右端、子节点连线的汇聚处有一个小圆圈：圈里一道横线是展开着，再加一道竖线是收着，点它收起或展开子节点。
- 图的右上角是缩放：− 缩小、+ 放大，中间的百分比是相对「刚好放得下」时的尺寸。
- 按住鼠标左键或右键在图上拖着走，整张图跟着手走，按在节点上或空白处都一样；拖动之后松手不会误触折叠或跳转。
- 点「导出图片」，当前的图按原尺寸存成一个 SVG 文件放在这篇笔记旁边（折叠着的节点照旧折着，小圆圈也画在图上），同名的不覆盖，会另取一个名字。需要打开文件夹；笔记不在文件夹里，图片就存在文件夹最外层。
- 点末端节点跳到笔记里的那一行；在标签页里点，会切回那篇笔记。
